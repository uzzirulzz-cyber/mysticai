FAQ

Good to know.

Straight answers about what this version does today.

Does the builder really use AI?

Yes. The build endpoint calls Google Gemini from a server-side function. Add GEMINI_API_KEY locally or to your Vercel project to enable generation.

Where are my files and saved builds?

Selected files are sent to the Gemini endpoint for your build. Build history and generated HTML are stored in this browser’s local storage. There is no account or cloud project database.

Are subscriptions available?

No. The USD prices are a preview. Checkout, subscriptions, and plan enforcement have not been implemented.

Can I publish the generated site?

Download the generated HTML and deploy it separately. This version does not push projects to GitHub or deploy generated apps automatically.
